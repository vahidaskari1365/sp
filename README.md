# ترمه — فروشگاه اینترنتی پوشاک (Next.js + PostgreSQL)

فروشگاه کامل پوشاک با طراحی فارسی/راست‌چین، تاریخ شمسی، قیمت تومانی، موجودی جدا برای هر
ترکیب سایز و رنگ، سبد خرید و پرداخت (شبیه‌ساز درگاه ایرانی)، پنل مدیریت و ساختار
SEO/AEO/GEO آماده.

## اجرا

```bash
npx drizzle-kit push      # ساخت/به‌روزرسانی جدول‌ها با Drizzle
node scripts/seed.mjs     # دادهٔ نمونه: ۱۲ محصول، ۵ دسته، کد تخفیف، ۳ سفارش
npm run build && npm start
```

## قابلیت‌ها

**فروشگاه**

- صفحهٔ اصلی ادیتوریال با هیرو تصویری، پارالاکس/ریویل، مارکی، بنتوی لوک‌بوک و شمارندهٔ آماری
- فهرست محصولات با فیلتر دسته، سایز، رنگ، بازهٔ قیمت، فقط موجود، مرتب‌سازی و جست‌وجو (URL-based)
- صفحهٔ محصول: گالری، انتخاب رنگ/سایز با موجودی زندهٔ هر ترکیب، خرید سریع، JSON-LD محصول
- سبد خرید با ذخیره در مرورگر، کد تخفیف، سبد کشویی و نوار پیشرفت ارسال رایگان
- پرداخت: اعتبارسنجی سمت سرور، قفل موجودی در تراکنش، سه روش ارسال (پست/تیپاکس/پیک)، شبیه‌ساز درگاه
- صفحهٔ سفارش با تایم‌لاین وضعیت، کد رهگیری، وضعیت پیامک + صفحهٔ پیگیری با شمارهٔ سفارش/موبایل

**پنل مدیریت**

- داشبورد: درآمد، سفارش‌ها، میانگین سبد، نمودار سفارش‌های اخیر، هشدار موجودی، پرفروش‌ها
- محصولات: افزودن/ویرایش/حذف، تصاویر، ثبت ترکیب‌های سایز-رنگ با موجودی مستقل
- سفارش‌ها: فیلتر وضعیت، تغییر وضعیت، ثبت کد رهگیری، مشاهدهٔ اقلام و آدرس
- کد تخفیف: درصدی/ثابت با حداقل خرید، سقف تخفیف، محدودیت تعداد و فعال/غیرفعال

**زیرساخت**

- Drizzle ORM + PostgreSQL، احراز هویت مدیر با کوکی امضاشده (HMAC، HttpOnly)
- پیامک سفارش: کاوه‌نگار در صورت تنظیم کلید، در غیر این صورت شبیه‌سازی/لاگ
- SEO: متادیتای هر صفحه، sitemap داینامیک، robots (با قواعد ربات‌های AI)، JSON-LD (Product، Offer، FAQPage، Organization، BreadcrumbList)، تصاویر بهینه‌شدهٔ AVIF/WebP
- فونت وزیرمتن + نمایش لاتین، انیمیشن‌های سبک CSS/IntersectionObserver و احترام به `prefers-reduced-motion`

## متغیرهای محیطی

| کلید | توضیح |
| --- | --- |
| `DATABASE_URL` | اتصال PostgreSQL |
| `ADMIN_PASSWORD` | رمز ورود پنل |
| `AUTH_SECRET` | کلید امضای کوکی نشست |
| `NEXT_PUBLIC_SITE_URL` | آدرس عمومی برای canonical/sitemap |
| `KAVENEGAR_API_KEY`, `KAVENEGAR_SENDER` | پیامک واقعی سفارش (اختیاری) |

جزئیات اسکیل‌ها و راهبرد SEO در `SKILLS.md` آمده است.

## نکتهٔ اتصال درگاه واقعی

پرداخت در `src/app/api/payments/verify/route.ts` و `src/lib/checkout.ts` متمرکز است.
برای زرین‌پال کافی است در مرحلهٔ ساخت سفارش `PaymentRequest` را صدا بزنید و آدرس درگاه را
به‌جای `/pay/[token]` برگردانید؛ پس از بازگشت، `markOrderPaid` با تأیید `Verify` فراخوانی
می‌شود. کد رهگیری پست/تیپاکس نیز در همان تابع تولید و ثبت می‌شود.
